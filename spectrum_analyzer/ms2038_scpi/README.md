# MS20xxC SCPI Commands (Markdown conversion)

Это часть руководства по программированию Anritsu MS20xxC VNA Master (PN 10580-00306, Rev. L), содержащая описание SCPI-команд, конвертированная из PDF в Markdown. Весь технический контент сохранён на языке оригинала (английском); структура глав, подсистем и отдельных команд повторяет оглавление исходного документа. Файлы можно использовать для быстрого поиска по командам, синтаксису и параметрам.

Source: `ms2038.pdf` — Anritsu MS20xxC VNA Master Programming Manual, PN 10580-00306 Rev. L (SCPI portion, PDF pages 27–414).
